## Описание задачи

Разработка ML-моделей для предсказания биологической активности химических соединений против вируса гриппа.

**Целевые переменные:**
- IC50 (mM) — концентрация, при которой вещество подавляет 50% активности вируса
- CC50 (mM) — концентрация, при которой вещество токсично для 50% клеток
- SI (Selectivity Index) — индекс селективности (отношение CC50 к IC50)

**Данные:**
- Обучающая выборка: 751 молекула, 211 химических дескрипторов
- Тестовая выборка: 250 молекул
- Метрика оценки: средний RMSE по трём целевым переменным

### Этап 11. Сравнение различных методов логарифмического преобразования

В ходе предыдущих экспериментов было установлено, что логарифмическое преобразование целевых переменных критически важно для получения качественных предсказаний. Однако оставался открытым вопрос: является ли log1p оптимальным выбором, или другие виды логарифмического преобразования могут дать ещё лучшее качество.

Целевые переменные IC50, CC50 и SI имеют колоссальный разброс значений — от тысячных долей до тысяч единиц. Различные типы логарифмического преобразования по-разному сжимают этот диапазон, что может влиять на способность модели обучаться.

#### Проверенные методы

| Метод | Формула | Особенность |
|-------|---------|-------------|
| **log1p** | `log(1 + x)` | Базовый метод. Корректно обрабатывает нулевые значения |
| **log10** | `log10(x + 1e-8)` | Десятичный логарифм. Сжимает сильнее: log10(1000) = 3 |
| **log2** | `log2(x + 1e-8)` | Двоичный логарифм. Сжимает сильнее всех: log2(1000) ≈ 10 |
| **Box-Cox** | `(x^λ - 1)/λ` | Автоматически подбирает оптимальный параметр λ |
| **Yeo-Johnson** | вариация Box-Cox | Работает с отрицательными значениями |

#### Результаты эксперимента

| Метод преобразования | Score на Kaggle |
|---------------------|-----------------|
| log1p | 303.50 |
| log10 | ~307 |
| log2 | ~306 |
| **Box-Cox** | **295.85** |
| Yeo-Johnson | ~298 |

#### Вывод

**Лучший результат показал Box-Cox с результатом 295.85**, что на 7.65 пункта лучше, чем baseline с log1p (303.50).

Box-Cox превзошёл другие методы благодаря тому, что автоматически подбирает оптимальный параметр λ для каждого таргета индивидуально. Для IC50, CC50 и SI распределения отличаются, и единый подход (log1p, log10 или log2) не может быть оптимальным для всех трёх целей одновременно. Box-Cox решил эту проблему, найдя наилучшее преобразование для каждой целевой переменной отдельно.
